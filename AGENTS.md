# Antigravity Execution Rules (Turbo / Direct Mode)

## Autonomous Workflow & Auto-Approval
- **Direct Execution**: Do not pause to create blocking implementation plans or wait for plan approvals.
- **Immediate Action**: Proceed directly from problem understanding/diagnosis straight into writing tests, modifying code, and verifying results.
- **Full Autonomous Mode**: Always execute changes, run tests, and confirm fixes autonomously without interrupting the user for intermediate plan sign-offs.
- **Quality & Verification**: Always ensure code compiles, passes tests (TDD), and maintains clean architecture before concluding tasks.
