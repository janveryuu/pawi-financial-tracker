# Direct Autonomous Execution (Turbo Mode)

1. **No Plan Interruption**: Never pause for user approval on implementation plans or design outlines.
2. **Immediate Implementation**: Move directly from diagnosis/research to writing tests (TDD) and implementing the code.
3. **Autonomous Verification**: Run tests, check for compiler/type errors, and verify changes autonomously before reporting results to the user.
